# 별찾기 FindingStar

계절별 별자리를 찾아보는 웹앱입니다. 휴대폰의 **GPS와 자이로·나침반 센서**를 쓰는 **3D 천구 / AR 모드**가 들어 있습니다.
빌드 과정 없이 정적 파일만으로 동작하며, 설치형 웹앱(PWA)이라 오프라인에서도 쓸 수 있습니다.

## 주요 기능

| 메뉴 | 내용 |
| --- | --- |
| **오늘 밤** | 현재 위치의 전천 성도, 달의 위상과 월출 시각, 해넘이, 천문박명(완전히 어두운 시간), 관측 지수, 지금 잘 보이는 대표 별자리, 행성 위치 |
| **계절 별자리** | 봄·여름·가을·겨울 탭. 계절마다 저녁 9시 하늘을 그린 성도에 봄의 대곡선, 여름·겨울의 대삼각형, 페가수스 대사각형, 겨울의 대육각형 같은 길잡이 별 모양을 표시. 별을 따라가며 찾는 단계별 안내와 대표 별자리 20개의 신화·찾는 법 |
| **3D 천구** | 실제 별 2,851개(5.5등급까지), 88개 별자리 선과 이름, 해·달(위상 표시)·행성, 은하수, 지평선과 방위. 드래그로 회전하고 휠이나 두 손가락으로 확대·축소 |
| ├ 🧭 센서 | GPS 위치와 자이로·나침반으로 휴대폰이 가리키는 하늘을 그대로 보여줌. 가로·세로 화면 모두 지원. 좌우로 드래그하면 방위를 보정할 수 있음 |
| ├ 📷 AR | 후면 카메라 영상 위에 별자리를 겹쳐 표시. 두 손가락으로 시야각을 맞춤 |
| ├ 🔍 찾기 | 별자리, 별, 행성을 검색해 목표로 지정하면 “➡ 오른쪽으로 20°, ⬆ 위로 15°” 식으로 방향을 알려주고, 찾으면 진동으로 알림 |
| ├ ⏱️ 시간 여행 | 날짜와 시각을 바꾸거나 ±1시간/±1일씩 이동, 타임랩스 재생 |
| └ 🗂️ 표시 | 별자리 선·이름, 별 이름, 행성, 은하수, 지면, 지평 좌표선·적도 좌표선을 켜고 끔. 관측지 밝기(도심/교외/시골)에 따라 보이는 별의 등급 한계를 조정 |
| **도감** | 88개 별자리 전체를 검색하고 필터링(계절별, 대표, 지금 보이는 별자리). 별자리마다 성도, 으뜸별, 관측하기 좋은 달, 지금 고도와 방위, 뜨고 지는 시각 표시 |
| 기타 | 🔴 야간 모드(빨간 화면으로 눈의 암순응 유지), 위치 선택(GPS, 국내 주요 도시, 위도·경도 직접 입력), 설정 저장, 오프라인 캐시 |

## 실행

```bash
python3 -m http.server 8000   # 또는 npx serve .
# 브라우저에서 http://localhost:8000
```

> ⚠️ 휴대폰에서 **센서, GPS, 카메라**를 쓰려면 **HTTPS**로 접속해야 합니다(GitHub Pages, Netlify, Vercel 등).
> iOS Safari에서는 “센서” 버튼을 누를 때 뜨는 *동작 및 방향* 접근 요청을 허용해야 합니다.

### GitHub Pages로 배포

저장소 **Settings → Pages**에서 브랜치와 `/ (root)`를 선택하면 됩니다. 빌드 단계는 없습니다.

## 구조

```
index.html              앱 셸(페이지, 3D 천구, 패널, 시트)
css/app.css             스타일(반응형, 모바일 하단 탭 바)
js/astro.js             천문 계산 엔진(항성시, 세차, 해·달·행성 위치, 뜨고 지는 시각)
js/sky-renderer.js      캔버스 천구 렌더러(지평/적도 좌표, 스테레오/원근 투영, 선택, 목표 안내)
js/sensors.js           DeviceOrientation → 카메라 방향 변환, 위치, 후면 카메라
js/app.js               화면 전환(해시 라우팅), 페이지 렌더링, 3D 천구 컨트롤러
js/data/sky-data.js     별·별자리 선·은하수 데이터(자동 생성)
js/data/guide-ko.js     계절 안내, 대표 별자리 20개의 신화와 찾는 법, 도시 목록
tools/build_sky_data.py sky-data.js 생성 스크립트
sw.js, manifest.webmanifest, icons/   PWA
```

### 정확도

`js/astro.js`는 JPL의 근사 궤도 요소(1800–2050년 유효)와 달 섭동항, 지표면 시차 보정을 씁니다.
PyEphem과 비교했을 때 별, 해, 행성은 오차가 **1′ 안팎**, 달은 **약 2′** 이내였습니다(2026–2030년 서울 기준, 토성 최대 4′).

### 센서 좌표 변환

W3C DeviceOrientation 회전 행렬 `R = Rz(α)·Rx(β)·Ry(γ)`로 기기 좌표를 지표 좌표(동·북·천정)로 바꾸고,
후면 카메라 방향 `−z`와 화면 방향(`screen.orientation.angle`)으로 시야를 정합니다.

- **Android**: `deviceorientationabsolute` 이벤트의 절대 방위를 씁니다.
- **iOS**: `webkitCompassHeading`과 상대 방위의 차이를 원형 저역통과 필터로 추정합니다.
- 흔들림은 기저 벡터에 지수 평활을 걸어 줄입니다.

## 데이터 다시 만들기

